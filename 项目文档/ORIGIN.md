# Origin

LocalSecretReview v1.0.1 is newly implemented as an offline, metadata-only source review tool. No files, source snippets, or pattern tables from SecretFinder or the earlier SecretCanopy derivative are included. The earlier derivative remains a separate private repository with its original authors and GPL-3.0 notices intact. Its broad remote-fetch and raw-match behavior is deliberately absent here.

The repository owner is responsible for verifying any claimed personal contribution, permission to inspect inputs, and any use in a CVP application. This document records source history; it is not a claim of CVP approval or an independently assigned vulnerability.
